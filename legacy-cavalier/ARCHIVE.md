# Archive — ancienne app « Cavalier »

Ce dossier conserve l'application d'origine du dépôt (**Cavalier**, programme
d'entraînement au sol pour cavalier — PWA mono-fichier) telle qu'elle existait avant que
le dépôt ne devienne le projet **Boussole** (optimisation financière).

Conservée à titre d'archive. Le projet actif est à la racine du dépôt (voir le
[`README.md`](../README.md) racine).

```
index.html    → l'app Cavalier complète (HTML + CSS + JS en un seul fichier)
README.md     → doc de déploiement/installation de Cavalier
vercel.json   → ancienne config Vercel de Cavalier
```

Pour la redéployer seule : servir `index.html` en statique (Vercel, Netlify, GitHub Pages…).
