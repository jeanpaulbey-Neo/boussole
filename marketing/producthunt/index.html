Convertir en PNG (3 méthodes, de la plus nette à la plus rapide)
  1. Chrome DevTools (pixel-perfect, polices incluses) — ouvre le .svg dans Chrome → clic droit → Inspecter → sur la balise <svg> : … → Capture node screenshot. PNG à la dimension exacte.
  2. Canva / Figma — glisse le .svg dans une frame 1270×760 → Export → PNG.
  3. Convertisseur en ligne — un site « SVG to PNG » (régler la largeur à 1270).
Astuce : sers le dossier en local pour un rendu identique → python3 -m http.server 8000 puis ouvre http://localhost:8000/marketing/producthunt/.
